# ADR-0007: 画面デザインの方向性を「マッチセンター」(A2)にする

- ステータス: 承認
- 日付: 2026-11-05
- 決定者: 小田 裕貴
- 関連: specs/005-notice、specs/006-read-and-delivery-status

## コンテキスト

- 利用者は少年サッカーチームの役員・コーチ・保護者で、スマホで使う
- 役員が最も知りたいのは「お知らせを誰がまだ読んでいないか」と、その場で取れる次の行動(再通知)
- ポートフォリオとして、面接官が数秒見ただけでサービスの価値が伝わる画面にしたい
- デザイン案を12案(野球版6案、サッカー版6案)とスコアボード方針の発展案3案を作って比較した(デザインのキャンバスに保存)

## 決定

海外サッカー中継の画面をモチーフにした「マッチセンター」(A2)を採用する。

- 最新のお知らせを中継のスコア表示のように見せ、既読と未読を「18 - 6」の得点形式で表示する
- 既読率をボール支配率風の2色のバーで表示する
- 一覧の既読状況も「既読 - 未読」の得点形式に揃える
- 色:背景 #F4F6FA、文字と主要面 #0D1A3A(ネイビー)、アクセント #2BD0B8(ターコイズ)、未読 #B23A28 / #FF8A73
- 書体:本文は IBM Plex Sans JP、数字は Barlow Condensed
- 日本語の改行は文節単位(word-break: auto-phrase)、文字と背景のコントラストは WCAG AA を満たす

## 検討した選択肢

| 案 | 評価 |
|---|---|
| A スコアボード(電光掲示板) | 価値が一目で伝わるが、サッカーらしさは控えめ |
| A2 マッチセンター | 価値が一目で伝わり、サッカー観戦の感覚に最も近い。採用 |
| A3 ナイトゲーム | 高揚感はあるが暗い背景で「明るく」から外れる。将来のダークモードの参考にする |
| A4 マッチデー | 伝統的な雰囲気で、新しいサービスらしさが弱い |
| B〜F(戦術ボード、背番号、連絡帳、ワッペン、ボール) | 印象は強いが、役員の課題(未読の把握)との結びつきがAより弱い |

## 結果

良くなること:

- 役員の課題とその解決(未読数と再通知)が画面の最上部で完結する
- 得点形式という一貫した表現で、画面ごとの見せ方を揃えられる

悪くなること・受け入れるコスト:

- 数字の表現が多く、サッカーを見ない保護者には情報が多く感じられる可能性がある。保護者向けの画面では数字を減らす

## 見直す条件

- 保護者に見せたとき、得点形式の意味が伝わらなかった場合
