# ADR-0013: 名簿の閲覧範囲と、閲覧・変更の監査ログ

- ステータス: 承認
- 日付: 2026-11-07
- 決定者: 小田 裕貴
- 関連: ADR-0003、ADR-0011、ADR-0012、specs/003-roster(判断1・2・4・5)

## コンテキスト

- 名簿には子ども(選手)の表示名が入る。表示名は暗号化して保存する(ADR-0003)
- 保護者は自分に紐づく選手だけを見られる。代表・役員・コーチは全員を見られる(AC-003-08・09)
- 名簿の閲覧は「誰が・いつ・どの範囲を」を監査ログに残す(AC-003-11)。ADR-0003 は変更も記録するとしている
- 同じ表示名・同じ学年の選手の重複を警告する(AC-003-03)

## 検討した選択肢

| 論点 | 採用した案 | 退けた案 |
|---|---|---|
| 重複の見つけ方 | **同じ学年の選手(最大200人)を復号して、アプリの中で比べる** | 表示名の照合用ハッシュの列を足す(列の一致から同じ名前の存在が分かる) |
| 閲覧の記録 | **一覧・詳細を取得するたびに1件** | 同じ人・同じ範囲は1日1件にまとめる(いつ見たかが分からなくなる) |
| 保護者が見られる範囲 | **自分の子どもと、その子に紐づく他の保護者の表示名** | 自分の子どもの情報だけ |
| 変更の記録と削除 | **登録・編集・削除・紐づけも記録する(値は残さない)。削除は行ごと消す** | 閲覧と取り込みだけを記録し、論理削除にする |

## 決定

- 選手の表示名は暗号化する。学年・背番号は平文(ADR-0003)
- 重複の判定では、比べる前に前後の空白を除き、全角・半角と大文字・小文字をそろえる(NFKC で正規化して小文字にする)
- TeamPolicy に、選手の管理(代表・役員)、全員の名簿の閲覧(代表・役員・コーチ)を足す。保護者は自分に紐づく選手だけを、UseCase の問い合わせで絞り込んで返す
- 保護者が自分に紐づかない選手を ID で取得すると、存在しない場合と同じ404にする(AC-003-10)
- 監査ログの action は player.viewed_list・player.viewed・player.created・player.updated・player.deleted・player.guardians_changed・player.imported
- details には範囲(all / own)、絞り込みの条件(学年・背番号)、変わった項目の名前、件数だけを入れる。表示名は入れない

## 結果

良くなること:

- 保護者に他の家庭の子どもの名前が見えない
- 名簿を誰がいつ見たか、変えたかを、名前を残さずに追える

悪くなること・受け入れるコスト:

- 重複の判定のたびに、同じ学年の選手を復号する(1チーム200人までなので問題にならない)
- 名簿を開くたびに監査ログが1件増える

## 見直す条件

- 1チームの選手数の上限を大きく増やす場合は、重複の判定の方法を見直す
