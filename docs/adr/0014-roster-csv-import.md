# ADR-0014: 名簿の CSV 取り込みは、確認と確定で同じファイルを2回送る

- ステータス: 承認
- 日付: 2026-11-07
- 決定者: 小田 裕貴
- 関連: ADR-0003、specs/003-roster(判断3・6・7、AC-003-13〜19・21)

## コンテキスト

- 役員は年度初めに、手元の表(主に Excel)から選手を一括で取り込みたい
- 取り込む前に件数と先頭10行を確認し、確定するまで登録しない(AC-003-14)。1行でもエラーがあれば1件も登録しない(AC-003-15)
- Excel で保存した CSV は Shift_JIS のことが多い(AC-003-16)
- 選手の名前を、必要以上にサーバーに残したくない(ADR-0003)

## 検討した選択肢

| 論点 | 採用した案 | 退けた案 |
|---|---|---|
| 確認と確定 | **同じファイルを2回送る。確認の応答でファイルの SHA-256 を返し、確定でそれが一致するかを確かめてから、もう一度検査して登録する** | 確認のときに読み込んだ行をサーバーに一時保存し、確定では ID だけを送る(名前を一時保存することになる) |
| 重複の警告 | **CSV の中の重複と、既存の選手との重複を、確認の画面で警告する(確定はできる)** | 1人ずつの登録だけで警告する |
| 文字コード | **UTF-8 として正しく読めれば UTF-8(BOM は除く)、そうでなければ CP932(Windows の Shift_JIS)として読む** | 画面で文字コードを選んでもらう |

## 決定

- 上限は 1MB・500行(見出しを除く)。超えたら読み込まずに上限を示す(AC-003-17)
- 見出しは「表示名,学年,背番号」。列の並びは見出しで判断する
- エラーは「3行目 学年:『小7』は選べません」の形で、見出しを1行目として数えた行番号・列・理由を返す
- `=` `+` `-` `@` で始まる値も、文字列のまま保存する(AC-003-18)。CSV を出力するとき(第3弾以降)は、出力の側で無害化する
- 確定のときは、選手の上限(200人)も含めてもう一度すべて検査する。1件でもエラーなら1件も登録しない
- テンプレートは UTF-8(BOM 付き)で、見出しと記入例1行
- CSV の読み込みには、PHP の標準の機能(fgetcsv、mb_convert_encoding)を使う。外部のライブラリは足さない

## 結果

良くなること:

- 選手の名前を、取り込みの途中でサーバーに残さない
- Excel で保存したファイルを、そのまま取り込める

悪くなること・受け入れるコスト:

- 確認と確定で、同じファイル(最大1MB)を2回送る
- UTF-8 としても CP932 としても正しく読めてしまう、ごくまれなファイルは UTF-8 として扱う

## 見直す条件

- Excel 以外(Google スプレッドシートの書き出しなど)で、文字コードの判定を誤る例が出た場合
